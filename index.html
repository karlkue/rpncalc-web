About RPN Calculator

RPN Scientific Calculator (Web & Mobile PWA)

Faithful modern recreation of the open-source RPN Calculator for Windows.

Keyboard Shortcuts (Desktop):

  • F5 - F8: Base (Dec, Hex, Bin, Oct)
  • F9 - F11: Angle (Rad, Deg, Grad)
  • Enter / Space: Push to stack / Duplicate
  • Backspace: Delete digit / Drop TOS
  • Escape: Clear all stack (CLA)
  • Direct Commands: Type function names (e.g. neg, sin, cos, swap, drop, sqrt) and press Enter.
