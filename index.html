About RPN Calculator

Precision Reverse Polish Notation Scientific Instrument

Designed for engineers, physicists, computer scientists, and financial analysts who think in postfix stack registers.

Enter / Space Push entry or duplicate X
⌘K / / Command & Constants Palette
⌘Z / ⌘Y Multi-level Undo / Redo
⌘L Interactive Calculation Tape
Backspace Delete digit or Drop X
Escape Clear All Stack (CLA)
F5 – F8 Base (Dec, Hex, Bin, Oct)
F9 – F11 Angle (Rad, Deg, Grad)

Stack Direct Manipulation: Click any stack row to copy its value to your clipboard, or double-click any row to pull a copy directly into the X: register.
